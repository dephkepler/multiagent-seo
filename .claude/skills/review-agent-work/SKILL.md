# Виктор Степаныч — Review Agent Work

Сабагента — на соответствие правилам проекта.

Не путать с `/code-review` (ищет баги корректности + reuse/simplification/efficiency в дифе). Этот
skill включается уже после того, как **сабагент** отчитался "сделано", и сверяет то, что он реально
написал, с писаными правилами проекта — не принимает отчёт сабагента на слово.

## Зачем отдельно
Сабагент стартует с холодным контекстом и не всегда держит `.claude/rules/*.md` так же плотно, как
основной поток разговора — особенно на длинных задачах. Частые проколы: package stutter
(`articles.ArticleStatus` вместо `articles.Status`), проглоченная ошибка через `_`, `log.*Context(...)`
прямо перед `return ...err` в не-хендлерном пакете, функция на две темы сразу.

## Область дифа
1. По умолчанию — `git status --short` + `git diff` (несохранённые изменения).
2. Если в дифе вперемешку правки сабагента и то, что правил сам пользователь в этом же сеансе, или
   сабагентов было несколько подряд — спроси, какие файлы/задача относятся к проверяемому сабагенту,
   не угадывай.

## Правила, по которым сверяем
`.claude/rules/naming.md`, `error-handling-logging.md`, `solid-dry-kiss.md` — уже загружены через
корневой `CLAUDE.md`, перечитай их файлы перед проходом (не по памяти — правила могли обновиться).
Полные версии с примерами «было→стало» — `doc/standards/`.

## Проход
1. По каждому изменённому/новому файлу в дифе — сверяй построчно с чек-листами всех трёх правил
   (naming: «Чек-лист на ревью»; error-handling: пункты 1-7 + «Enforcement»; solid-dry-kiss:
   SOLID/DRY/KISS секции).
2. Только то, что реально нарушено **в этом дифе** — не переоценивай существующий код вокруг,
   которого сабагент не касался.
3. На каждую находку: `file:line` → какое правило нарушено (дословная цитата или номер пункта из
   `.claude/rules/*.md`) → в чём конкретно → какой фикс предлагаешь. Коротко, без воды.
4. Ничего не правь молча. Список находок — пользователю, жди решения по каждой (фиксить сейчас /
   потом / это не нарушение).

## Если находок нет
Скажи прямо: диф чист, ничего не нарушает `.claude/rules/*.md`. Не выдумывай находки ради отчёта.
